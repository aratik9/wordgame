
# 🧠 Marathi Word Game | मराठी शब्द गेम

A simple and fun Marathi word guessing game built using HTML, CSS, and JavaScript.

मराठी शब्द गेम हा एक छोटा आणि मजेदार वेब गेम आहे. दिलेल्या अक्षरांवरून योग्य मराठी शब्द ओळखा आणि गुण मिळवा!

## 🎮 Live Demo

👉 https://aratik9.github.io/wordgame/

## ✨ Features

- Marathi language word guessing game
- Multiple-choice answers
- Score tracking
- Instant feedback for correct and incorrect answers
- Simple and user-friendly interface
- Responsive layout for mobile and desktop
- Built with HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/aratik9/wordgame.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing!
